# 🚀 Personal Portfolio Website

A responsive and modern web development portfolio built with **React**, **TypeScript**, and **Vite**. The entire development workflow and environment setup were executed in the cloud using **StackBlitz**.

🌐 **Live Demo:** [Portfolio](https://pronobportfoliio.netlify.app/)

💻 **StackBlitz Workspace:** [Explore and edit the code](https://stackblitz.com/edit/vitejs-vite-ua2svyzk?file=index.html)

---

## ✨ Features

* 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
* ⚡ **Fast Performance:** Powered by Vite for ultra-fast load times and HMR.
* 🛡️ **Type-Safe:** Built with TypeScript for cleaner code and robustness.
* ☁️ **Cloud IDE:** Fully developed, configured, and tested online using [StackBlitz](https://stackblitz.com/).
* 🎨 **Modern UI/UX:** Interactive showcases for projects, skills, and contact info.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React
* **Language:** TypeScript
* **Build Tool:** Vite
* **Development Environment:** StackBlitz
* **Hosting/Deployment:** Netlify
